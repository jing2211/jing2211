# Скиллы для сайтов, Telegram-ботов и игр

Здесь хранится подобранный набор инструкций для AI-ассистентов. Исходные файлы взяты из [Agentic Awesome Skills](https://github.com/sickn33/agentic-awesome-skills) на коммите `f6f686855a672e3868d648cef056312392e3a417` (22 ноября 2026 года). Файлы скиллов сохранены без изменений; отбор и этот README добавлены для удобства.

| Задача | Скиллы |
| --- | --- |
| Дизайн и разработка сайтов | `frontend-design`, `frontend-developer`, `web-design-guidelines`, `web-performance-optimization`; `react-best-practices` для React и Next.js |
| Проверка сайтов | `e2e-testing-patterns` |
| Telegram-боты | `telegram-bot-builder`, `nodejs-backend-patterns` для Node.js; `python-pro`, `python-testing-patterns` для Python |
| Браузерные игры | `game-development` с разделами `web-games`, `2d-games`, `3d-games`, `game-design`; `3d-web-experience` для 3D в браузере |
| Unity | `unity-developer`; `unity-ecs-patterns` для проектов на DOTS/ECS |
| Поиск причин ошибок | `systematic-debugging` |
| Проверка и защита кода | `code-review`, `lint-and-validate`, `api-security-best-practices` |

Ранее сохранённые `threejs-lighting` и `threejs-materials` также полезны для браузерных 3D-игр.

**GitHub хранит файлы, но не подключает их автоматически.** Для Codex установите нужные папки с `SKILL.md` в каталог скиллов Codex. Для ChatGPT, если в вашем аккаунте доступна функция Skills, загрузите каждый нужный скилл через **Plugins → Skills → Create → Upload from your computer**. Перед установкой проверьте инструкции и дополнительные файлы скилла. Большой набор обычно не нужен для одной задачи: выбирайте подходящие скиллы по проекту.

Лицензии исходного проекта и перечень его источников сохранены в [`licenses/agentic-awesome-skills`](licenses/agentic-awesome-skills). У отдельных скиллов могут быть собственные условия; сохранены их исходные файлы лицензий и сведения в `SKILL.md`.
